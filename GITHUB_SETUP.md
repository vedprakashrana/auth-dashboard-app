# GitHub Setup Instructions 🎯

## 1️⃣ Add Topics/Tags to Your Repository

Topics help people discover your project on GitHub!

### Steps:
1. Go to your repository: **https://github.com/vedprakashrana/auth-dashboard-app**
2. Click on the **⚙️ Settings** icon (gear icon) next to "About" on the right side
3. In the "Topics" field, add these tags:
   ```
   react
   nodejs
   mongodb
   express
   dashboard
   authentication
   mern-stack
   jwt
   tailwindcss
   full-stack
   task-management
   glassmorphism
   modern-ui
   ```
4. Click **"Save changes"**

You should see these tags appear below your repository name!

---

## 2️⃣ Enable GitHub Pages (Optional)

GitHub Pages lets you host a static demo of your frontend!

### Steps:
1. Go to your repository: **https://github.com/vedprakashrana/auth-dashboard-app**
2. Click on **"Settings"** tab (top menu)
3. Scroll down to **"Pages"** in left sidebar
4. Under **"Source"**, select:
   - Branch: `main`
   - Folder: `/ (root)` or `/docs` (if you create a docs folder)
5. Click **"Save"**

**Note:** Since this is a full-stack app with backend APIs, GitHub Pages will only work for static documentation or if you deploy the frontend separately. For full app hosting, consider:
- **Frontend**: Vercel, Netlify
- **Backend**: Heroku, Railway, Render
- **Database**: MongoDB Atlas

## 6️⃣ Add Social Preview Image

Make your repo look professional when shared on social media!

1. Go to **Settings** → **Options**
2. Scroll to **"Social preview"**
3. Click **"Upload an image"**
4. Upload `screenshots/banner.png` from your project
5. Click **"Save"**
